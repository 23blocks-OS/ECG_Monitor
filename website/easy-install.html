What the Installer Does

Our interactive installation wizard automates everything:

  • ✅ Validates prerequisites (AWS CLI, Terraform, Python, Node.js)
  • ✅ Guides you through configuration with simple questions
  • ✅ Deploys complete AWS infrastructure automatically
  • ✅ Generates Raspberry Pi configuration files
  • ✅ Provides step-by-step setup instructions
  • ✅ Creates organization and user accounts
  • ✅ Gives you dashboard URLs and next steps

Prerequisites (Quick Checklist)

Before You Start

  1. AWS Account

    Create a free AWS account at aws.amazon.com. You'll need a credit card but won't be charged unless you exceed free tier limits (~$25-50/month expected).

  2. Install AWS CLI

    Download and install AWS CLI v2 from aws.amazon.com/cli, then run aws configure with your AWS access keys.

  3. Install Terraform

    Download Terraform >= 1.5.0 from terraform.io. Extract and add to your PATH.

  4. Claude API Key

    Sign up at console.anthropic.com and create an API key. You'll get $5 free credits.

  5. Hardware (Optional for Now)

    You can deploy cloud infrastructure first, then set up Raspberry Pi hardware later. Hardware needed: Raspberry Pi 4 ($55), CJMCU-1293 ECG module ($25), accessories ($35).

Installation (15-20 Minutes)

  1. Clone Repository

    git clone https://github.com/23blocks-OS/ECG_Monitor.git
cd ECG_Monitor

  2. Run One-Click Installer

    ./install.sh

    The installer will:

    • Check if prerequisites are installed
    • Ask simple questions about your setup
    • Deploy AWS infrastructure (takes ~10 minutes)
    • Generate all configuration files

  3. Save the Outputs

    When deployment finishes, save these important URLs:

    • API Gateway URL: For dashboard connectivity
    • IoT Endpoint: For Raspberry Pi connection
    • Dashboard URLs: If deployed to CloudFront

  4. Deploy Dashboards (Optional - Can Use Vercel)

    Easiest: Deploy to Vercel for free hosting

    # Install Vercel CLI
npm install -g vercel

# Deploy patient portal
cd dashboard-next
npm install
vercel deploy --prod

# Deploy provider portal
cd ../dashboard-org
npm install
vercel deploy --prod

  5. Access Your Dashboards

    Visit the Vercel URLs provided. In development mode, any credentials work for testing.

🎉 That's It for Cloud Setup!

Your cloud infrastructure is ready. You can now:

  • Access dashboards and explore the interface
  • Set up Raspberry Pi hardware when ready (see docs/raspberry-pi-deployment.md)
  • Create organization and users for multi-patient support
  • Test with mock data before connecting real hardware

Raspberry Pi Setup (When Ready)

After cloud deployment, set up your Raspberry Pi device:

  1. Flash Raspberry Pi OS

    Use Raspberry Pi Imager to install OS on microSD card (32GB+)

  2. Connect CJMCU-1293 Hardware

    Connect ECG module to Pi via SPI (see docs for pinout)

  3. Run Pi Setup Script

    scp config/pi-config-deployed.yaml pi@raspberrypi:~/
ssh pi@raspberrypi

git clone https://github.com/23blocks-OS/ECG_Monitor.git
cd ECG_Monitor
./scripts/setup-pi.sh

  4. Start Services

    python3 pi-collector/main.py &
python3 pi-streamer/main.py &
