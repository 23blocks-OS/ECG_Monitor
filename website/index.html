How It Works

Edge + Cloud Hybrid Architecture

🫀

1. Data Capture

Raspberry Pi + CJMCU-1293 ECG module captures 3-lead cardiac signals

→
📡

2. Stream to Cloud

MQTT over TLS to AWS IoT Core with offline buffering

→
🧠

3. AI Analysis

Lambda + Claude AI detects arrhythmias and patterns

→
📱

4. Real-Time Insights

Web dashboards with alerts and recommendations
