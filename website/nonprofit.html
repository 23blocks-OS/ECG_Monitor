Why This Exists

Healthcare monitoring shouldn't be limited to wealthy institutions. This project was created to democratize access to professional cardiac monitoring for communities that need it most. If you're a nonprofit serving patients who can't afford expensive medical devices, this is for you.

What You Get (100% Free)

  • ✅ Zero Licensing Costs
    No fees, ever. You own the software and run it yourself.
  • ✅ Provider Portal
    Doctors and nurses monitor all patients from one dashboard
  • ✅ Patient Portal
    Patients view their own ECG data and health insights
  • ✅ Multi-Patient Support
    Unlimited patients, organization management, role-based access
  • ✅ AI-Powered Analysis
    Claude 3.5 Sonnet detects arrhythmias automatically
  • ✅ Real-Time Alerts
    Email notifications when anomalies detected
  • ✅ Device Pool Management
    Share ECG monitors across patients efficiently
  • ✅ Complete Source Code
    Customize for your specific needs and protocols

Cost Breakdown

While software is free, you'll need to cover infrastructure and hardware:

Small Clinic (20 patients, 5 devices)

Hardware (one-time) 5 × Raspberry Pi + ECG modules $575
AWS (monthly) IoT Core, Lambda, DynamoDB, S3 $25-50
Claude API (monthly) AI analysis with 10% sampling $20-40
Software License ECG Monitor platform $0 - FREE
Monthly Operating Cost $45-90

Medium Clinic (50 patients, 10 devices)

Hardware (one-time) 10 × Raspberry Pi + ECG modules $1,150
AWS (monthly) Increased usage $50-100
Claude API (monthly) AI analysis $40-80
Software License ECG Monitor platform $0 - FREE
Monthly Operating Cost $90-180

💡 Cost Savings vs Commercial Systems

Commercial ECG monitoring systems typically cost $5,000-15,000 per device + $200-500/month per patient. This solution saves 90%+ in costs.

Your Journey (2 Hours Setup)

  1. Run One-Click Installer

    Use our guided installer to deploy complete AWS infrastructure

    git clone https://github.com/23blocks-OS/ECG_Monitor.git
cd ECG_Monitor
./install.sh

  2. Deploy Dashboards

    Deploy provider and patient portals to Vercel (free hosting)

    cd dashboard-org && npm install && vercel deploy --prod
cd dashboard-next && npm install && vercel deploy --prod

  3. Create Organization

    Set up your clinic organization, admin users, and staff roles

  4. Configure Raspberry Pi Devices

    Set up each ECG monitoring device with patient assignments

  5. Train Staff

    Show doctors and nurses how to use provider portal

  6. Onboard Patients

    Create patient accounts and show them the patient portal

Eligibility

You qualify for free licensing if your organization:

  • ✅ Operates as a registered nonprofit (501(c)(3) in US or equivalent)
  • ✅ Provides healthcare services
  • ✅ Serves patients regardless of ability to pay, OR
  • ✅ Serves underserved/low-income populations

No paperwork required. This is an honor system. We trust nonprofits to use this ethically.
