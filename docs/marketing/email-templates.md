## Email Best Practices

### Subject Line Tips
✓ Keep under 50 characters
✓ Create curiosity or urgency
✓ Include specific numbers/benefits
✓ Avoid spam triggers ("FREE!!!", "ACT NOW!!!")
✓ Personalize when possible

### Body Copy Tips
✓ Lead with value, not features
✓ Use short paragraphs (2-3 lines max)
✓ Include specific numbers and examples
✓ One primary CTA (clear next step)
✓ P.S. often gets read - use it strategically

### Personalization
✓ Use recipient's name
✓ Reference their organization
✓ Mention specific pain points
✓ Show you've done research
✓ Connect to their mission/work

### Response Optimization
✓ Make it easy to reply (ask questions)
✓ Provide calendar link for bookings
✓ Offer resources without requiring action
✓ Give multiple engagement options
✓ Follow up but don't spam
