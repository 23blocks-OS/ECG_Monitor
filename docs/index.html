August 13, 2024: I had a heart attack at age 49 while training for my 11th Ironman triathlon. I had completed 10 Ironmans and was in peak physical condition—or so I thought. A 95% blockage in my "widowmaker" artery changed everything.

I survived. I recovered 100% (rare). And exactly one year later, I finished Ironman Arizona—the race I was training for when my heart gave out.

This ECG monitoring system was born from that experience. But the story—and the lessons about heart disease prevention—are too important not to share.

Why ECG Monitor?

Beyond basic heart rate tracking. Detect what consumer devices can't.

🤖

AI-Powered Analysis

Claude 3.5 Sonnet analyzes ECG metrics to detect arrhythmias, AFib, PVCs, and patterns that traditional devices miss.

  • Atrial Fibrillation detection
  • PVC identification
  • Heart rate variability analysis
  • Pattern recognition (rest/exercise)
⚡

Real-Time Monitoring

Continuous 24/7 heart monitoring with near real-time web dashboard displaying waveforms, metrics, and alerts.

  • 250 Hz sampling rate
  • 3-lead ECG configuration
  • 5-second dashboard updates
  • Live waveform visualization
☁️

Cloud Infrastructure

Scalable AWS architecture with IoT Core, Lambda, DynamoDB, and S3 for reliable data processing and storage.

  • Serverless compute (Lambda)
  • Real-time data streaming (IoT Core)
  • Automatic scaling
  • Cost optimized (~$45-85/month)
📧

Intelligent Alerts

Email notifications when anomalies are detected, with severity levels and 15-minute cooldown to prevent spam.

  • 4 severity levels (low to critical)
  • HTML email templates
  • Smart cooldown logic
  • Actionable recommendations
🏃

Exercise Tracking

Monitor heart activity during workouts. AI distinguishes between rest, exercise, and stress patterns.

  • Activity pattern detection
  • Exercise vs rest classification
  • Stress indicator analysis
  • Recovery monitoring
🛡️

Privacy & Control

Your data, your infrastructure. Deploy to your own AWS account with complete control and security.

  • Self-hosted on your AWS
  • X.509 certificate authentication
  • Encrypted data transmission
  • No third-party data sharing

Get Started in Minutes

Deploy your personal ECG monitoring system

1

Clone Repository

git clone https://github.com/23blocks-OS/ECG_Monitor.git cd ECG_Monitor
2

Configure AWS & API Keys

# Configure AWS CLI aws configure # Set Claude API key export CLAUDE_API_KEY="your-api-key-here"
3

Deploy with Terraform

cd terraform/environments/poc terraform init terraform apply

Or use the automated deploy script: ./deploy.sh

4

Verify Deployment

# Check IoT endpoint terraform output iot_endpoint # Open dashboard terraform output dashboard_url
1

Prepare Raspberry Pi

Install Raspberry Pi OS (64-bit recommended) and enable SSH

2

Transfer Files

scp -r ECG_Monitor pi@raspberrypi.local:/home/pi/
3

Run Automated Setup

ssh pi@raspberrypi.local cd ECG_Monitor/pi-collector ./setup_pi.sh

Setup takes ~15 minutes. Script handles all dependencies and configuration.

4

Start Services

sudo systemctl enable ecg-collector ecg-streamer sudo systemctl start ecg-collector ecg-streamer
1

Generate Test Data

cd tests/data python3 generate_test_data.py

Creates 14 test files with realistic ECG waveforms (normal, PVC, AFib, tachycardia)

2

Run System Simulator

cd tests/simulators python3 ecg_system_simulator.py --scenario afib

Simulates end-to-end pipeline from Pi to dashboard

3

Run Integration Tests

cd tests/integration ./test_end_to_end.sh
