# The Heart of an Ironman - eBook Project

## Overview

This directory contains all materials for **"The Heart of an Ironman"**, a free eBook created to raise awareness about heart disease prevention, particularly among people who consider themselves "too healthy" to be at risk.

**Mission**: Get this life-saving message into the hands of as many people as possible.

## 📥 Download Options

### Current Format
- **Markdown** (.md): Available now for immediate download

### Recommended Future Formats
1. **PDF** (for desktop/printing)
   - Create using Canva, Adobe InDesign, or Google Docs
   - Dimensions: 6" x 9" or 8.5" x 11"
   - Resolution: 300 DPI
   - File size: Under 20 MB

2. **ePub** (for e-readers: Kindle, Apple Books, Kobo)
   - Convert using Calibre (free tool)
   - Reflowable text for all screen sizes

3. **Print Version** (optional)
   - Upload to Amazon KDP, Lulu, or Blurb
   - Print-on-demand for physical copies

### Conversion Tools
- **Calibre** (free): Markdown → ePub/MOBI
- **Pandoc** (free): Universal document converter
- **Canva** (free/pro): Design PDF version
- **Adobe InDesign** (paid): Professional layout
